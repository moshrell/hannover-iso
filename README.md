# hannover-iso — изометрическая карта Ганновера и региона

Будущая страница «Webdesign Hannover & Region» на kravets-webdesign.de: изометрическая карта в стиле ISO-glow
(`D:\Webdesign\_tools\iso-glow`, лицензия MIT, © Tolga Cohce / iso-figure — копирайт в коде не удалять, текст в `LICENSE-iso-glow.txt`).

## Сейчас
- **`karte.html` — карта «Hannover Mitte» из готовых плиток** (как Google/OSM-карты). Браузер ничего не рисует, только показывает картинки WebP:
  - открывается сразу: постер (`tiles/poster.webp`, 150 КБ) виден в первую же долю секунды, плитки догружаются по месту;
  - Вся город Ганновер (≈17×21 км, ~170 тыс. зданий, 29 тыс. деревьев). 5 уровней приближения (0,094 / 0,375 / 0,75 / 1,5 / 3 пикселя на метр, для экранов ×2): во всём городе до 0,75, в центре (`data/bbox.json` → `core`, Linden–Oststadt–Maschsee) все 5. Вне центра карта после жеста сама мягко отъезжает до резкого масштаба. 8422 плитки, 83 МБ. Грузятся только видимые плитки; на экране рисуется на одном холсте, под новыми плитками всегда две более грубые ступени (нет чёрных вспышек).
  - перетаскивание/щипок/колесо/двойной щелчок/кнопки — своим кодом, 60 кадров/с в проверке (раньше живой SVG из 44 000 элементов вешал телефон);
  - город всегда вечерний (свет включён). Анимации включения света на общей карте больше нет — она и тормозила.
  - **Нажатие на точку** (или карточку под картой) → окно с живой студией здания: у каждого здания своя точка и общая студия `studio.html?lm=<имя>` (строится из `core/` + `landmarks/mitte.js`, рамка по рисунку). Режим `embed`: только рисунок и кнопка. Там свет включается по этажам (≈ 7 с) и остаётся; кнопка «Abendlicht» переключает на ночь. Кнопка в окне стоит по центру и не прыгает (`embed.js` ставит режим до отрисовки); на телефоне рисунок крупнее (края сцены обрезаны).
  - На карте нет надписей (ничего не закрывают): только светящиеся точки, по одной на каждое здание, над самой высокой точкой рисунка (`tools/scene.js` → `pinOf`, позиции в `tiles/meta.js`; нет позиции — нет точки, а не точка в углу). Имя — при наведении мышью и в окне. Список карточек под картой — обычный HTML (Google видит). Подпись «© OpenStreetMap-Mitwirkende (ODbL)» внизу.
  - Старт: Neues Rathaus крупно и кусок Maschteich под ним (`START` в `karte.js`).
- **Сборка плиток** (в облаке; весь город ≈ 45 мин, точечно вокруг изменённых зданий — минуты: `node tools/render-tiles.mjs --at lat,lon,радиус_м`, плитки вмешиваются в `tiles/`): `node tools/render-tiles.mjs` → `tools/render.html` + `tools/scene.js` готовят все части сцены, а SVG строится заново для каждого блока только из частей, которые в него попадают (иначе город слишком тяжёлый); Playwright фотографирует блоки, `tools/cut-tiles.py` режет на плитки, выкидывает пустые, пишет `tiles/meta.js` и постер. Длинную сборку не оставлять в фоне между сообщениями: облачная машина засыпает и процесс умирает.
- Крыши фона: двускатные и вальмовые из OSM (`roof:shape`, ~490 домов), остальные плоские.
- Вся карта повёрнута на ≈ 15,8°, чтобы Neues Rathaus стоял как в студии (пруд слева снизу). Достопримечательности стоят на реальных местах по своим осям; их OSM-контуры убраны из фона.

## Устройство
- `core/iso-core.js` — общий движок: проекция, «ядро» модуля (поворот, масштаб, перенос на место), стены/крыши/купола/фронтоны, сортировка частей, часы.
- `core/iso.css` — все материалы, цвета и переходы света.
- `landmarks/<имя>.js` + `landmarks/meta/<имя>.json` — достопримечательности, **одно здание = свои файлы** (код модуля `ISO.landmark(...)`, метаданные: заголовок, тексты, OSM-id или точка, высота, сторона фасада). Общие файлы `landmarks/all.js` и `landmarks/meta.js` генерирует `tools/build-landmarks.py` (их не править руками). Новое здание: `python3 tools/new-landmark.py`. Работа в нескольких чатах — см. **`ARBEIT.md`**.
- `data/bbox.json` — границы карты (`all` — город, `core` — центр с мелкими уровнями); `data/osm.json.gz` — данные OSM из выгрузки BBBike (`https://download.bbbike.org/osm/bbbike/Hannover/Hannover.osm.pbf`, доступна из облака, обновляется еженедельно) через `python3 tools/osm-extract.py Hannover.osm.pbf S,W,N,E data/osm.json.gz` (формат как у Overpass, `prep.py` не меняется). `data/q.txt` — старый запрос Overpass (только для истории).

## Студии (подробно)
- **Neues Rathaus** — теперь тоже в общей студии (`studio.html?lm=neuesRathaus`, модуль `landmarks/neues-rathaus.js`; старая отдельная `rathaus.html` удалена). План здания по OSM-контуру r313173 (дворы 22×38 м, крылья ≈12 м, средний блок 61 м, портал с двумя восьмигранными башнями), мансардная крыша среднего блока, стеклянная крыша у основания купола. Фото-референсы Google Earth: `ref/neuesrathaus/foto/` + `INDEX.md` + `README.md`. Все кадры снимать одним ракурсом: наклон 54°, направление ≈331°.
- **Свет (вечер)** — по порядку, как в жизни, ~7 с (темп — `SPEED = .55` в `studio.js`): фонари → окна мерцают и зажигаются по этажам (с разбросом) → прожекторы заливают фасад снизу вверх → фонарь купола последним. Дальше «живой» режим: фонарь «дышит», звёзды мерцают, около дюжины окон изредка гаснут на миг. Окна неоднородны (22 % тёмные, 20 % приглушённые, 14 % яркие) — иначе плотные фасады сливаются в светлое пятно. На каждой стене три полупрозрачных слоя (`wsh`/`wsl`): верх темнее, цоколь теплее. После показа остаётся включённым; выключает кнопка «Abendlicht».
- **Размеры**: пропорции сцены заданы до отрисовки (ничего не прыгает). Телефон: колонкой, кнопка сразу под картинкой. От 900 px: текст и кнопка слева, рисунок справа, всё в высоту экрана (макс. 880 px ширины). Края сцены мягко растворяются (маска), без жёстких обрезов пруда.
  - **Marktkirche** (Рыночная церковь): кирпичный зал под крутой красной крышей, контрфорсы с песчаниковыми крышками, стрельчатые окна, 7/10-хор на востоке. Башня 97 м: песчаниковые углы, звонница с жалюзи, четыре фронтона (на юге часы и гексаграмма, на востоке часы и пентаграмма — как в реальности), крест-крыша и дахрайтер (маленькая башенка на крыше) с медным шпилем — светится последним.
  - **Altes Rathaus** (Старая ратуша): аркада, двойные окна, глазурованные фризы, три зверхауза (мансардные фронтоны) со ступенчатыми фронтонами, большой ступенчатый Schaugiebel (парадный фронтон) с фиалами (башенками-шпилями).
  - **Leineschloss** (Ляйнешлосс, ландтаг): песчаник, мансардная крыша со слуховыми окнами, портик Лавеса с 6 коринфскими колоннами и фронтоном, лестница, стеклянный Plenarsaal (зал пленарных заседаний).
  - Фон: река Leine (Ляйне) слева, Hannah-Arendt-Platz с деревьями, Marktplatz (Рыночная площадь), Leinstraße.
  - Свет: каждое здание подсвечивается от своего основания, с небольшим сдвигом (Ляйнешлосс → ратуша → церковь → башня); часы башни — одновременно.
  - Фото-референсы: `ref/altstadt/01–16.jpg` (Wikimedia Commons).
- Движок: свои модули с сортировкой «дальше → ближе», SVG без WebGL.

## Решения
- Только тёмный фон сайта (#0A0E0C), без палитр. От скилла ISO-glow — только формула проекции (MIT).
- Масштаб стилизованный (1 ед. ≈ 1 м, купол 98,5 м). Общая карта — «nicht maßstabsgetreu».
- Вращение убрано (решение Степана): один ракурс доводится до идеала.
- На карте два масштаба: «hero» с полной детализацией при приближении и упрощённый силуэт (LOD) издалека — купол, башни, красные крыши, тёплый свет.

## Тексты для Google (всё живым HTML, не внутри SVG)
- title «Webdesign Hannover – Webseiten für Betriebe ab {prices.base} € | Kravets»; h1 «Webdesign für Hannover und die Region».
- Вступление 2–3 предложения: кто, откуда (Gehrden), что получает бизнес, цена из `site.ts`.
- Подписи объектов карты: 1–2 факта на объект, продублированы списком под картой (уникальный местный контент + доступность).
- «Was eine Seite für Betriebe in Hannover braucht»: Impressum, Datenschutz/DSGVO, связка с Google-Profil, онлайн-запись 24/7, мобильная версия, скорость, свой домен и почта.
- Kosten прозрачно (пакет, Pflege, ориентир хостинга — из `site.ts`), Ablauf кратко + ссылка, «Ich komme zu Ihnen».
- «Kunden auf der Karte» — список клиентов обычными ссылками (с первыми клиентами).
- FAQ 6–8 реальных вопросов простым HTML (разметку FAQPage не ставить: Google показывает её почти только госсайтам).
- Внутренние ссылки с главной, /kontakt, /arbeiten; разметка `Service` с `areaServed` Hannover без дубля адреса.
- Не делать: списки районов ради ключевых слов, одинаковые тексты для разных городов (Doorway Pages).

## Известно
- Деплой по FTP идёт 10–15 минут и не атомарный: пока он идёт, на сайте может быть смесь старых и новых файлов (точки в углу, старые картинки зданий, дыры в плитках). Смотреть карту — после зелёного «Deploy Website to FTP». `karte.js` не рисует точку без позиции в `tiles/meta.js`.
