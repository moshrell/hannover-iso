# hannover-iso — изометрическая карта Ганновера и региона

Будущая страница «Webdesign Hannover & Region» на kravets-webdesign.de: изометрическая карта в стиле ISO-glow
(`D:\Webdesign\_tools\iso-glow`, лицензия MIT, © Tolga Cohce / iso-figure — копирайт в коде не удалять, текст в `LICENSE-iso-glow.txt`).

## Сейчас
- **`karte.html` — карта «Hannover Mitte» (главный файл).** Открыть двойным щелчком (рядом должны лежать папки `core`, `landmarks`, `data`). `?sofort` — свет сразу.
  - Основа — OpenStreetMap: ~1600 реальных домов (высота из OSM: `height` или этажи × 3,3 м), улицы, Ляйне, Maschteich, парки, ~2100 деревьев. Подпись «© OpenStreetMap-Mitwirkende (ODbL)» обязательна — стоит внизу страницы.
  - Вся карта повёрнута на ≈ 15,8°, чтобы Neues Rathaus стоял ровно как в студии `rathaus.html` (пруд слева снизу). Север не вверху — для стилизованной карты это нормально.
  - Достопримечательности ручной работы стоят на реальных местах, повёрнуты по своим реальным осям (OSM-контур → минимальный прямоугольник): Neues Rathaus, Marktkirche, Altes Rathaus, Leineschloss. Их OSM-контуры из фона убраны.
  - Управление своим кодом (без библиотек): перетаскивание, щипок двумя пальцами, колесо мыши, двойной щелчок, кнопки + − ⤢. Подписи — настоящие HTML-кнопки (перелёт к зданию), под картой список с фактами (живой текст для Google).
  - Вечер: точки фонарей вдоль улиц → окна города волной от центра → окна достопримечательностей по этажам → подсветка фасадов (Ляйнешлосс → Старая ратуша → Marktkirche → Neues Rathaus) → часы → фонари куполов. Первый раз сам включается и гаснет, дальше кнопкой.
  - Скорость: ~21 600 SVG-элементов, отрисовка ≈ 0,3–0,6 с; при движении карта двигается целиком как картинка (плавно и на телефоне).
- Студии (эталоны деталей, остаются для сравнения): `rathaus.html`, `altstadt.html`.

## Устройство
- `core/iso-core.js` — общий движок: проекция, «ядро» модуля (поворот, масштаб, перенос на место), стены/крыши/купола/фронтоны, сортировка частей, часы.
- `core/iso.css` — все материалы, цвета и переходы света.
- `landmarks/*.js` — достопримечательности: `ISO.landmark('имя', H => ({ mods, lc, len, label, top }))`. Новая = новый файл + строка в `prep.py` (OSM-id) + `<script>` в `karte.html`.
- `data/q.txt` — запрос Overpass; `data/osm.json` — сырые данные OSM; `data/prep.py` — превращает их в `data/mitte.js` (метры, поворот, сортировка «дальше → ближе» по разделяющим осям). Пересборка: `python3 prep.py osm.json mitte.js`.

## Студии (подробно)
- `rathaus.html` — Neues Rathaus v4, **один ракурс**: вид с юга, пруд Maschteich слева снизу. Открыть двойным щелчком; `?sofort` — свет сразу, без анимации.
  - Север/восток/запад в коде остались (модули рисуются, т.к. видны крыши и углы), но отдельных видов нет — фото других сторон только как справка.
  - Детали: пилястры, карнизы, руст цоколя, переплёты, замковые камни, зверхаузы, фонари, часы с реальным временем.
- **Свет (вечер)** — по порядку, как в жизни, ~6,8 с (темп — константа `SPEED = .765` в коде): фонари → окна по этажам снизу вверх (с разбросом) → прожекторы заливают фасад снизу вверх (стены светлеют только теперь) → все циферблаты башенных часов одновременно (один контур) → фонарь купола последним. Выключение — в обратном порядке. При первом открытии один раз включается и через ~10 с гаснет сам, дальше только кнопкой «Abendlicht» (нажатие во время показа отменяет авто). `prefers-reduced-motion` — без анимации.
- **Размеры**: пропорции сцены заданы до отрисовки (ничего не прыгает). Телефон: колонкой, кнопка сразу под картинкой. От 900 px: текст и кнопка слева, рисунок справа, всё в высоту экрана (макс. 880 px ширины). Края сцены мягко растворяются (маска), без жёстких обрезов пруда.
- `altstadt.html` — старый город v1, тот же стиль, свет и раскладка страницы. `?sofort` — свет сразу.
  - **Marktkirche** (Рыночная церковь): кирпичный зал под крутой красной крышей, контрфорсы с песчаниковыми крышками, стрельчатые окна, 7/10-хор на востоке. Башня 97 м: песчаниковые углы, звонница с жалюзи, четыре фронтона (на юге часы и гексаграмма, на востоке часы и пентаграмма — как в реальности), крест-крыша и дахрайтер (маленькая башенка на крыше) с медным шпилем — светится последним.
  - **Altes Rathaus** (Старая ратуша): аркада, двойные окна, глазурованные фризы, три зверхауза (мансардные фронтоны) со ступенчатыми фронтонами, большой ступенчатый Schaugiebel (парадный фронтон) с фиалами (башенками-шпилями).
  - **Leineschloss** (Ляйнешлосс, ландтаг): песчаник, мансардная крыша со слуховыми окнами, портик Лавеса с 6 коринфскими колоннами и фронтоном, лестница, стеклянный Plenarsaal (зал пленарных заседаний).
  - Фон: река Leine (Ляйне) слева, Hannah-Arendt-Platz с деревьями, Marktplatz (Рыночная площадь), Leinstraße.
  - Свет: каждое здание подсвечивается от своего основания, с небольшим сдвигом (Ляйнешлосс → ратуша → церковь → башня); часы башни — одновременно.
  - Фото-референсы: `ref/altstadt/01–16.jpg` (Wikimedia Commons).
- Движок: свои модули с сортировкой «дальше → ближе», SVG без WebGL.

## Решения
- Только тёмный фон сайта (#0A0E0C), без палитр. От скилла ISO-glow — только формула проекции (MIT).
- Масштаб стилизованный (1 ед. ≈ 1 м, купол 98,5 м). Общая карта — «nicht maßstabsgetreu».
- Вращение убрано (решение Степана): один ракурс доводится до идеала.
- На карте два масштаба: «hero» с полной детализацией при приближении и упрощённый силуэт (LOD) издалека — купол, башни, красные крыши, тёплый свет.

## Ограничения карты v1
- Фон: все крыши плоские (скатные из OSM пока не рисуются), фасады без материалов.
- Altes Rathaus с этого ракурса виден в основном торцом (так он стоит в реальности); остальные крылья комплекса пока пустая площадка.
- Leineschloss: к зрителю — сторона Ляйне с зимним садом; портик Лавеса с этого ракурса не виден (он на Leinstraße).
- Отражений в воде на карте пока нет (были в студии).
- Край карты — по прямоугольнику запроса OSM, поэтому неровный.

## Ограничения Altstadt v1
- Расположение стилизовано: длинная сторона Старой ратуши повёрнута к зрителю (в реальности смотрит на Marktplatz к церкви), расстояния сжаты.
- Нет фахверковых домов (Kramerstraße, Burgstraße), Beginenturm, Historisches Museum — кандидаты на v2.
- Движок пока скопирован в каждый файл; при сборке карты вынести в общий `iso-core.js`.

## Ограничения v4
- Дворовые фасады упрощены, крыши крыльев — простые вальмы.
- Светофильтр окон висит всегда (для плавного выключения) — на слабых телефонах проверить плавность.

## План
1. ✅ Один ракурс + логичный вечерний свет + размеры → ждёт оценки; затем дорисовка деталей в этом ракурсе.
2. ✅ Altstadt v1 → ждёт оценки.
3. ✅ Карта Mitte на OSM v1 (`karte.html`) → ждёт оценки. Дальше: больше районов, LOD, детальные крыши фона.
4. Hauptbahnhof + Ernst-August, Opernhaus, Welfenschloss (ур. 2), Herrenhäuser Gärten + Große Fontäne, Maschsee, Telemax, Expo-Dach (ур. 3). Без логотипов (96, üstra).
5. Домики клиентов из JSON (имя, координаты, ссылка) — только с письменного согласия.
6. Страница на сайте + тексты (ниже); потом карта Gehrden на том же движке.

## Тексты для Google (всё живым HTML, не внутри SVG)
- title «Webdesign Hannover – Webseiten für Betriebe ab {prices.base} € | Kravets»; h1 «Webdesign für Hannover und die Region».
- Вступление 2–3 предложения: кто, откуда (Gehrden), что получает бизнес, цена из `site.ts`.
- Подписи объектов карты: 1–2 факта на объект, продублированы списком под картой (уникальный местный контент + доступность).
- «Was eine Seite für Betriebe in Hannover braucht»: Impressum, Datenschutz/DSGVO, связка с Google-Profil, онлайн-запись 24/7, мобильная версия, скорость, свой домен и почта.
- Kosten прозрачно (пакет, Pflege, ориентир хостинга — из `site.ts`), Ablauf кратко + ссылка, «Ich komme zu Ihnen».
- «Kunden auf der Karte» — список клиентов обычными ссылками (с первыми клиентами).
- FAQ 6–8 реальных вопросов простым HTML (разметку FAQPage не ставить: Google показывает её почти только госсайтам).
- Внутренние ссылки с главной, /kontakt, /arbeiten; разметка `Service` с `areaServed` Hannover без дубля адреса.
- Не делать: списки районов ради ключевых слов, одинаковые тексты для разных городов (Doorway Pages).
