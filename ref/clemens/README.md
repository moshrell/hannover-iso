# Basilika St. Clemens — отчёт (ветка `lm/clemens`)

## Что сделано
- `landmarks/clemens.js`: фронтон с порталом и лестницей (восток), корпус-«крест» с медной кровлей, боковые рукава, апсида, две башни на западных углах, барабан с 8 парами окон, медный купол с 20 рёбрами, светящийся фонарь с вогнутой шапкой, шар и крест, статуи на углах кровли, пристройка у южной башни.
- Геометрия идеализирована симметрично по оси OSM-контура (way 357786647); `face: ["compass",[1,0],[1,0]]`, фасад смотрит на восток (Platz an der Basilika лежит к востоку, проверено по OSM).
- Материалы по палитре карты: `pl` светлый камень/штукатурка, `gb` оранжевая штукатурка (в палитре читается тепло-золотой), `cu` патинированная медь.
- Проверки: studio-shot 390×760 и 1000×700 (здание целиком, ошибок консоли нет), preview.sh (на своём месте, фасад вправо-вниз, старого OSM-дома нет).

## Что не удалось / допущения
- Wikimedia Commons отдавал 429 на общем IP; часть запросов (Rückseite, Luftbild) пришлось заменить обходом категории `St. Clemens (Hannover)` и медленной загрузкой, часть файлов не скачалась.
- Северная сторона и точное расположение башен (какая на север/юг) по фото не однозначны; обе башни рисуются одинаково.
- Пропорции барабана, радиус купола, положение статуй, ниш и южной пристройки оценены по фото на глаз, не по обмерам.
- Цвет: палитра карты не имеет настоящего оранжевого, штукатурка передана золотистым тоном.
- Статуи упрощены (токарные фигуры из `lathe`).

## Факты, не сверенные
- **Высота 47 м** — только из OSM (комментарий «from former informations»); второго источника не нашлось. Помечена как непроверенная.
- Проверены по двум источникам (en.wikipedia, hannover.de): Бауцайт 1712–1718, Basilica minor 1998 (Иоанн Павел II), послевоенные купол и колокольни, бронзовые порталы Х. Г. Бюкера.
- Только en.wikipedia: архитектор Томмазо Джусти, освящение 4.11.1718, начало восстановления 1946, освящение 24.11.1957. В `studio` использованы только эти формулировки.

- Сборщику: перегенерировать `landmarks/all.js` и `landmarks/meta.js` (мной не коммитятся).
