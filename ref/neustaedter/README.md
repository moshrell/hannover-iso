# Neustädter Hof- und Stadtkirche (neustaedter) — Bericht

Ветка `lm/neustaedter`. Модуль `landmarks/neustaedter.js` (v1 вырезан из `mitte2.js`), meta `landmarks/meta/neustaedter.json`. Сравнение: `vergleich-1.png` (слева наш рисунок, справа кадр `v_01`).

## Что нарисовано
- Контур — из OSM w29173386 (поворот 11°): башня на западе (x 0–9,4), поперечный западный блок с двумя фронтонами на север и юг (x 8–16,4, y 0–31,2), зал 35,5×21 м (Traufe 10 м, First 17 м, вальма на востоке), более узкий хор на востоке (x 51,9–59,1).
- Башня: серый песчаник, ярусные пояса, арочные окна, светлый карниз, восьмигранник с часами, «шапка» с фонарём (светится вечером) и шпилем. Цвет шапки — `bk` (в движке нет коричневой меди; `cu` даёт зелёную патину, на кадрах шапка тёмно-коричневая).
- Зал: арочные окна + малые окна верхнего ряда, один ряд мансардных окон на южном скате, медный наконечник у северо-восточного угла (на кадре виден бирюзовый).

## Не видно / по аналогии
- Нижние ярусы башни и западный портал (закрыты деревьями/блоком), кровля над хором, число осей окон на северной стороне.
- Число мансард (11) и ритм окон зала (8 осей) — приблизительно, по кадрам v_01/v_05.

## Не сверено
- Высота башни (≈ 72 м) и высота зала: Wikipedia (de/en) цифр не даёт, оценка по кадрам; нужен второй источник.
- Вид северной стороны скрыт при фиксированном ракурсе, мансарды на северном скате не рисуются.

## От движка / сборщика
- Нужен материал «коричневая медь» (`cu` — патина). Сейчас использован `bk`.
- Здание в зоне детальных плиток (центр Нойштадта), расширять зону не нужно.
- Проверки: карточка 390×760 и 1000×700 без ошибок консоли; на карте (`SCENE.region`) стоит на месте, башней на запад.
