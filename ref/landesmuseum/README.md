Факты (en.wikipedia + пресс-релиз landesmuseum-hannover.de)
Здание 1897–1902, архитектор Hubert Stier, неоренессанс (Neorenaissance); фриз Georg Herting и др.; купол над риалитом сгорел при налёте 8.10.1943; ремонт крыш с 2019 (первоначально семь стеклянных крыш); открытие после реконструкции 13.5.2000.
