# Landesmuseum — отчёт о доработке (ветка `lm/p_landesmuseum`)

Файлы: `landmarks/landesmuseum.js`, `landmarks/meta/landesmuseum.json`, `ref/landesmuseum/` (INDEX.md, vergleich-3/4/5.png, foto/, ansicht_1–5.jpg, quellen.txt).

## Итоги доработки
- Размер на карте: OSM-контур 82 м (длинная сторона), `len` модуля 83 м, `fit` ≈ ×0,99. Здание на карте стоит главным фасадом (риалит с порталом) к Willy-Brandt-Allee, `face: street` не менялся; сверено с v_10/v_11.
- Точка: `pin: [41.5, 33.1, Z0 + 31]`, то есть над серединой участка, выше крыши риалита. Проверено `tools/preview.sh landesmuseum 3`.
- Карточка: `card_phi` не задан (0). Проверены 0, −45, 45, 90: при 0 в изометрии видны главный фасад с порталом и зелёные люкарны павильона, при ±45 вид вырождается в почти плоский (кровли в полный рост), при 90 главный фасад не виден. Ошибок порядка рисования нет.
- Стеклянные крыши: на боковых флигелях вместо двух фонарей по одному длинному (как на v_01/v_04/v_11); вместе с 2 + 2 на переднем/заднем флигелях и центральным павильоном на тыльном их семь, как в источниках.
- Передние флигели: пять осей окон вместо четырёх (как на ansicht_1), оконные ниши и рельефная полоса подогнаны.
- Купол ротонды теперь серо-синий шифер/цинк (на v_05/v_10/v_11 он не зелёный), зелёная медь осталась только на люкарнах павильонов.
- `minor` убран (здание крупное, точка видна всегда).
- Метаданные: добавлены `seo` (109 слов), `addr`, `year`, `arch`; `studio` уточнён («lange Glasoberlichter»).
- Из `ref/` удалены `ansicht_6.jpg` (не Landesmuseum) и устаревшие `vergleich-1/2.png`.

## Не видно / по аналогии
- Тыльный и боковые фасады рисованы по аналогии (кадры видны только под большим углом).
- Двор упрощён: стеклянная кровля над входом в ротонду и остекление двора не детализированы.
- Высоты (карниз 15,5 м, павильоны 20,5 м, риалит 23,6 м, итого 27,5 м) оценены по кадрам, в источниках не найдены.
- Число оконных осей на боковых фасадах по v_06/v_07 приблизительное.

## Не проверено
- Адрес «Willy-Brandt-Allee 5, 30169 Hannover», год 1902 (окончание строительства 1897–1902), архитектор Hubert Stier, открытие после реконструкции в 2000 г.: по Wikipedia (en) и пресс-релизу Landesmuseum из прошлого отчёта; в этой сессии повторную проверку прервал лимит запросов, второй источник не перечитан.
