# Markuskirche — отчёт

**Что нарисовано.** Модуль `landmarks/markuskirche.js`: длинный неф (steiles Satteldach, шифер), три щипца на северо-западной стене, хор на востоке, башня посередине южной стороны (≈ 70 м) с восьмигранным шпилем, две низкие пристройки. Из OSM только общий контур `w44834907` (одним полигоном), поэтому части и высоты подобраны вручную по кадрам (`ref/markuskirche/gen/gen-mk.py`, `TEILE.md`). 17 выпуклых кусков, SVG ≈ 12 КБ.

**Сравнения.** `vergleich-1.png` (v_03, вид на СЗ-стену и башню), `vergleich-2.png` (v_06, вход под башней), `vergleich-3.png` (v_05, западный щипец). Расстановка частей и силуэт совпадают; отличия: у настоящей башни более богатый декор, роза и аркады на щипцах не нарисованы.

**По аналогии / не видно.** Хор и восточная сторона, декор башни, контрфорсы, угловые башенки. Высоты стен и коньков оценены по пропорциям кадров (±2 м).

**Непроверенные факты.** Архитектор О. Люэр, 1902–1906, башня ≈ 70 м, 400 бетонных свай (de.wikipedia и de-academic совпадают); тип/материал кладки в источниках не указан, рисую как тёмный камень.

**Нужно от сборщика/core.**
1. Идея Степана: в карточке рисовать здание лицевой стороной (на карте реальная ориентация). Для этого нужен поворот `phi` в `studio.js`; у каждого здания в meta можно хранить лицевую сторону (`face`). Здесь «лицо» — южная сторона с башней.
2. `tools/map-crop.mjs` не вызывает `SCENE.region` (пустая картинка); путь CHROME по умолчанию (chromium-1194) неверный.
3. Якорь `point` [52.3883, 9.7523, 90 м] + `osm` w44834907.
