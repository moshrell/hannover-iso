# Markuskirche — отчёт

**Что нарисовано.** Модуль `landmarks/markuskirche.js`: светлый песчаник (цвет по k01/k02), башня по центру южного фасада (≈ 70 м, шпиль), два южных щипца с розой, арочными окнами и медной окантовкой, круглая башенка с зелёной крышей справа, неф с крутой шиферной крышей и тремя щипцами на СЗ-стороне, хор на востоке, низкий западный входной щипец перед большим (двойная крыша спереди). Окна нефа и щипцов с арками. Из OSM только общий контур `w44834907`; части и высоты подобраны по кадрам (`gen/gen-mk.py`, `TEILE.md`). 11 частей, 25 кусков, SVG лёгкий.

**Сравнения.** `vergleich-1.png` (k01, юг), `vergleich-2.png` (v_06), `vergleich-3.png` (v_03). Расстановка и цвет совпадают; башня у модели грубее (нет колокольни и ступенчатых контрфорсов), шпиль тоньше настоящего.

**По аналогии / не видно.** Порталы и аркады под южными щипцами, восточный хор, колокольня, верх шпиля, контрфорсы. Высоты оценены по кадрам (±2 м).

**Непроверенные факты.** О. Люэр, 1902–1906, башня ≈ 70 м, 400 бетонных свай (de.wikipedia и de-academic совпадают).

**Нужно от сборщика/core.**
1. Идея Степана: в карточке рисовать здание лицевой стороной (на карте реальная ориентация). Для этого нужен поворот `phi` в `studio.js`; у каждого здания в meta можно хранить лицевую сторону (`face`). Здесь «лицо» — южная сторона с башней.
2. `tools/map-crop.mjs` не вызывает `SCENE.region` (пустая картинка); путь CHROME по умолчанию (chromium-1194) неверный.
3. Якорь `point` [52.3883, 9.7523, 90 м] + `osm` w44834907.
