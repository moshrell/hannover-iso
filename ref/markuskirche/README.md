# Markuskirche — отчёт

**Что нарисовано.** Модуль `landmarks/markuskirche.js`: светлый песчаник (цвет по k01/k02), башня по центру южного фасада (≈ 70 м, шпиль), два южных щипца с розой, арочными окнами и медной окантовкой, круглая башенка с зелёной крышей справа, неф с крутой шиферной крышей и тремя щипцами на СЗ-стороне, хор на востоке, низкий западный входной щипец перед большим (двойная крыша спереди). Окна нефа и щипцов с арками. Из OSM только общий контур `w44834907`; части и высоты подобраны по кадрам (`gen/gen-mk.py`, `TEILE.md`). 11 частей, 25 кусков. Детали (часы, аркады колокольни, розы со спицами, пилястры, патина на коньках, 4 декоративных щипца под шпилем) перенесены из доработки p_markuskirche; её планировка (башня на углу) заменена по кадрам k01/k02.

**Сторона → кадры.**
| Сторона | Кадры |
|---|---|
| Юг (башня, два щипца) | k01-sued, v_06, v_08 |
| Юго-запад (западная группа щипцов) | k02-suedwest, v_04, v_05 |
| СЗ (щипцы) | v_01, v_02, v_03 |
| Восток (хор) | v_07 (закрыт деревьями) |

**Сравнения.** `vergleich-1.png` (k01, юг, карточка card_phi −30), `vergleich-2.png` (k02, ЮЗ), `vergleich-3.png` (v_03, СЗ-стена). Старые vergleich-4..6 (прежняя планировка) удалены.

**По аналогии / не видно.** Порталы и аркады под южными щипцами, восточный хор, колокольня, верх шпиля, контрфорсы. Высоты оценены по кадрам (±2 м).

**Непроверенные факты.** О. Люэр, 1902–1906, башня ≈ 70 м, 400 бетонных свай (de.wikipedia и de-academic совпадают).

**Нужно от сборщика/core.**
1. Идея Степана: в карточке рисовать здание лицевой стороной (на карте реальная ориентация). Для этого нужен поворот `phi` в `studio.js`; у каждого здания в meta можно хранить лицевую сторону (`face`). Здесь «лицо» — южная сторона с башней.
2. `tools/map-crop.mjs` не вызывает `SCENE.region` (пустая картинка); путь CHROME по умолчанию (chromium-1194) неверный.
3. Якорь `point` [52.3883, 9.7523, 90 м] + `osm` w44834907.

**Карта и карточка.** Масштаб ×1,0 (точка `[52.3883, 9.7523, 60]`, len 60). Карта показывает здание с юго-востока: южный фасад с башней, два щипца, башенка. Карточка: `card_phi` −30, лицом на юг (как k01). Это одна и та же модель.

**Раунд k03–k11** (кадры Степана, вплотную): западный фасад — большой щипец с мозаичным арочным окном и крыльцо перед ним (двойная крыша), угловые восьмигранные башенки с шиферными шатрами; юг — щипец с розой и аркадой из 5 окон, фиала у щипца; башня — часы наверху, под ними парные арки звона, угловые фиалы и 4 щипца у шпиля; восток — полигональная апсида (5/8) с шатровой крышей и низкая ризница. Кадры: k03/k10 юг, k04/k05 башня, k06/k09 запад и север, k07/k08 север и восток, k11 апсида. Направление слайдера в Google Earth (−180…180): юг ≈ 20°, запад ≈ 105°, восток ≈ −70°.
По аналогии: форма ризницы, северные угловые башенки, ширина апсиды.
