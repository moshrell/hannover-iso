# Hauptbahnhof — заметки для сборщика (ветка `lm/hauptbahnhof`)

Что сделано: модуль вынесен из `mitte.js` в `landmarks/hauptbahnhof.js` (первый коммит), фасад и памятник перерисованы по фото Wikimedia (`ansicht_*`, `denkmal_*`, источники в `quellen.txt`), `landmarks/meta/hauptbahnhof.json` заполнен.

## Сделать сборщику
- Слить ветку в `main`, затем `python3 tools/build-landmarks.py` → `prep.py` → `render-tiles.mjs` (один раз на партию). `landmarks/all.js` и `landmarks/meta.js` в ветку не коммичены (генерируются).
- Параметры `CLEAR['hauptbahnhof']` в `data/prep.py` не менялись: площадь без домов, статуя на оси центрального портала (проверено на карте).
- Движку (`core/`) новых материалов не нужно.

## Известные ограничения
- Всадник — плоский силуэт на плоскости (+ тёмная копия со сдвигом 0,35 м для объёма). Объёмная фигура потребовала бы новой функции в `core/`.
- Уровень деталей фасада рассчитан на карточку и приближение карты; на общей карте мелкие детали (медальоны, Rundbogenfries, радиальные решётки арок) не видны.
- Порталы в цоколе рисуются светящимися, но с этого ракурса их закрывает стеклянный Vordach (как в жизни).
- Тексты в meta: архитектор Hubert Stier и год 1879 проверены по английской Wikipedia; скульптор Albert Wolff и год 1861 — по одному сайту (equestrianstatue.org), по Wikipedia не сверено.
- Фото-референсы только для сверки, в рисунок не копировались; логотипов (DB, магазины) нет.

## Баг в инструментах
- `tools/setup-cloud.sh`, запущенный как `sh tools/setup-cloud.sh` (относительный путь), не создаёт симлинк `node_modules` и не стартует сервер: `cd /tmp/pw` ломает `dirname "$0"`. Лечится вызовом по абсолютному пути или правкой скрипта (я его не трогал: не мой файл).
