# Leineschloss (Landtag Niedersachsen) — отчёт

Ветка `lm/leineschloss`, OSM r1170793. Здание то самое (id не менялся).

## Что нарисовано
Весь комплекс по плану OSM в осях контура (172,1 × 74,7 м): «хвост» (северо-западное крыло) с угловым павильоном, средний и юго-восточный павильоны, длинное крыло к реке с лоджией, крыло Лавеса к площади (Laves-Flügel) с плоскими крышами и фасадом к площади, внутренний двор, фойе со стеклянной пирамидой, портик (шесть колонн, ступени, фронтон), блок Пленарного зала с красной каймой, тёмной вальмовой крышей и четырьмя люками. Мансарды с люкарнами (на скрытых скатах не рисуются).
