# Anzeiger-Hochhaus (anzeiger) — отчёт

Ветка `lm/anzeiger`. Модуль `landmarks/anzeiger.js` (v1 вырезан из `mitte2.js`), meta `landmarks/meta/anzeiger.json` (`face`: локальное +y → запад). Сравнение с кадром: `vergleich-1.png` (слева наш вид на карте, справа `v_07`).

## Что нарисовано
- Контур по OSM w304133007: восточный ригель 32,3×14,2 м (длинный фасад на Goseriede) и западный выступ 22×9,4 м; единый объём до карниза 46 м.
- Фасады: тёмный клинкер, пилястры (шаг 2,3 м), узкие окна рядами по 3,3 м, щелевые окна под карнизом, арочный цокольный этаж, острые навершия пилястр на карнизе.
- Купол: зелёная медь, R ≈ 11 м, высота ≈ 12 м, по центру плана (диаметр ≈ ширина дома, как на кадрах).
- Вечер: светятся щелевые окна, световые полосы на пилястрах и надпись ANZEIGER (по ночному фото `anzeiger-nacht.jpg`; надпись и полосы нарисованы классом `wn hi`, цвет тёплый, а не голубой — в движке нет голубого неона).

## По аналогии / не видно
- Уступы и боковые блоки у западной стороны (на `anzeiger-foto1` справа тёмный более высокий объём, слева низкий блок с эркерами) не нарисованы: объём упрощён до одного яруса.
- Число осей и этажей посчитано по кадрам приблизительно (≈ 15 осей по длинной стороне, 11 этажей).
- Окна нижних этажей и арки входов нарисованы схематично, мелкие надстройки у основания купола (острые «ушки») опущены.

## Не сверено
- Высота (карниз 46 м, с куполом ≈ 59 м): задание даёт 56 м (по ориентировке), второй источник не проверялся.
- Высота и пропорции купола оценены по кадрам.

## От движка / сборщика
- Нужен голубой «неон» для светодиодных линий (сейчас тёплый `wn hi`).
- Здание в зоне детальных плиток (центр), расширять зону не нужно.
- Проверки: карточка 1000×700 без ошибок консоли; карта (`SCENE.region`) — на месте, купол над длинным восточным фасадом.
