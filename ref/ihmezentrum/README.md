# Ihme-Zentrum — отчёт

**Что нарисовано.** Весь комплекс как один модуль (`landmarks/ihmezentrum.js`): 63 части OSM (`building:part`: подиум 10/15 м, ряды 16–47 м, башни 70–89 м), 277 выпуклых кусков с собственной сортировкой по глубине. Окна — по одному `<path>` на класс×группу этажей на стену; цоколь с лентой магазинов; красная полоса на южных башнях; светящаяся вывеска enercity вверху западной башни. Вес SVG ≈ 290 КБ (3250 узлов) — тяжелее, чем обычное здание (HKW ≈ 55 КБ), но комплекс 150 м.

**Сторона → кадры.**
| Сторона | Кадры |
|---|---|
| Юг | v_18, v_19 |
| Восток / башни | v_02, v_10 |
| Север/река | частично v_02, v_10; в ISO-виде скрыта |
| Крыши | облёт v_01…v_20 |

**По аналогии (кадров не хватило).** Северные фасады и балконы, внутренние дворы, детали крыш. Свет окон: доля горящих ≈ 1/3 по ночным фото, равномерно-случайно.

**Непроверенные факты.** 860 квартир, открытие 31.10.1974, высота башни enercity 89 м (из OSM), состояние/реконструкция — по Википедии, второй источник не сверен.

**Сравнения.** `vergleich-1.png` (юг, v_19 — совпадает силуэт, пропорции, башни), `vergleich-2.png` (v_02), `vergleich-3.png` (v_10; ракурс повёрнут примерно — направление камеры подбиралось на глаз).

**Нужно от сборщика/core.**
1. Здание задано `point` [52.370699, 9.718156, 150 м] + `osm` ids (съедаются контуры); prep удаляет дома внутри квадрата — проверь результат.
2. `tools/scene.js`: culling-квадрат зависит от размера якоря.
3. `tools/map-crop.mjs` даёт пустую картинку (не вызывает `SCENE.region`); в `tools/*` путь CHROME по умолчанию (chromium-1194) неверный.
4. osm-extract выбрасывает `building:part`; комплекс есть только как part — данные встроены из OSM API (`ref/ihmezentrum/gen/`, парсер и `embed.py`).
5. Комплекс внутри зоны core (bbox 52.3542–52.3995, 9.682–9.7618).
6. Разбиение: один mod (фасады одной точки зрения, сортировка внутри), логические группы: подиум, прибрежная полоса, южная полоса, северное крыло, башни. Если сборщик захочет тоньше SVG — можно уменьшить число окон (`STRIP/TOWER`).
