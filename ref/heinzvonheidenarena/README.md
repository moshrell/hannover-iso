# Heinz von Heiden Arena — отчёт о доработке (ветка `lm/p_heinzvonheidenarena`)

Файлы: `landmarks/heinzvonheidenarena.js`, `landmarks/meta/heinzvonheidenarena.json`, `ref/heinzvonheidenarena/` (INDEX.md, vergleich-3.png, foto/).

## Итоги доработки
- fit на карте: ×1,00 (OSM-размер 234 × 204 м, `len` = W = 233,5 м). Контур по OSM (relation 92928), `face: compass` не менялся.
- Точка: `pin: [C0x, C0y, Z0 + ZR + 4]`, то есть над серединой поля, чуть выше кабельного кольца (раньше стояла на северной кромке кровли). Проверено `tools/preview.sh`.
- Карточка: `card_phi = -30`. Восточный фасад с входом смотрит на зрителя, на дальней трибуне целиком читается надпись, как на кадре v_08. Ошибок порядка рисования нет (4 угла проверены: 45, −20, −30, −45, −60).
- Надпись «HEINZ VON HEIDEN» перенесена на нижний ярус западной трибуны и увеличена (82 м, кегль 8 м). Раньше стояла на верхнем ярусе и пряталась за кромкой кровли: для камеры с востока верхний ярус закрыт кровлей, виден только узкий нижний пояс у поля (так и на v_07/v_08).
- Новое: входной блок в середине восточного фасада (22 × 5,5 м, высота 10,5 м) с остеклением и красным табло «96» (класс `tl`).
- Мачты кабельного кольца реже (шаг ≈ 22 м вместо 15 м): меньше «забора», вес SVG ниже.
- Метаданные: добавлены `seo` (118 слов), `addr`, `year`, `arch`; в `studio` исправлено «восемь» башен на «десять» (в модуле их 10).

## Что не видно на кадрах / по аналогии
- Фасады N, W, S нарисованы по аналогии с E; боковые блоки по краям входа (на v_08 два выступа с рекламными табло) нарисованы только как OSM-башни.
- Кабельное кольцо и мачты: точное число и наклон мачт не измерены, на кадре они тоньше и реже.
- Высоты (фасад 12 м, кромка 14 м, проём 29 м, кольцо 34 м) оценены по кадрам; в OSM `h` = 35 м. Нужный второй источник по высоте не найден (hannover.de и structurae.net её не дают).
- Прожекторы (160 шт. в кровле) не рисуются; кадров ночью нет.
- Цвет кровли: в жизни светло-серая, в модуле тёплая палитра `pl` проекта (общий стиль, палитру не менял).

## Не проверено
- Номер дома: hannover.de даёт «Robert-Enke-Straße, 30169 Hannover» без номера; в `addr` номера нет.
- Факты сверены по двум источникам: Wikipedia (en) и structurae.net (открытие 26.09.1954, переустройство 2003–2005 Schulitz & Partner, ETFE-кровля, 49 000 мест), hannover.de (49 000 мест, 1954, названия).

## Для сборщика / core
- Плитки: пересобрать вокруг стадиона `node tools/render-tiles.mjs --at 52.3600,9.7314,160`.

- `core/` не менялся, от движка ничего не нужно.
