# Altes Rathaus: разбор кадров (ref/altesRathaus/foto/v_01 … v_11)

Кадры нарезаны из видео Google Earth (полный облёт, наклон около 54°). «Направление» = куда смотрит камера (значение с ползунка). У v_01 и v_02 ползунок слева, значение не видно: по виду ≈ как v_11 (≈ 227°).
Локальная система модуля: x = 0 — северо-западный торец (Marktfront, к Marktkirche), +x — юго-восточный торец; y = 0 — северо-восточная сторона, +y — юго-западная. Размер 54,4 × 35,7 м, оси повёрнуты на 49° к востоку (по OSM w5121356).

## Чеклист по сторонам
- SO-торец (x = 54,4, виден на карте): 35,7 м, ярус arcade внизу, два яруса окон, карниз; центральный Treppengiebel около 18 м. Леса закрывают фасад, поэтому членение окон взято по Marktfront и по SW-стене (по аналогии); боковые части с парными окнами видны на v_04.
- SW-стена (y = 35,7, виден как узкая полоса): NW-здание со Treppengiebel шириной 22 м, SW-крыло (x 22–38) выше, с серой плоской крышей и кондиционерами, SO-здание со Treppengiebel шириной 16,4 м. Везде внизу arcade, выше 2–3 ряда окон.
- Крыши: NW-здание — коньк вдоль y, крутой скат (в видимой стороне две мансардные), SO-здание — коньк вдоль y, пологий скат на SO, NO-крыло — коньк вдоль x с двумя мансардами, двор — стеклянная крыша ниже карниза.
- NW-торец (Marktfront) и NO-стена: хорошо видны на кадрах v_03, v_07–v_10, но на карте стоят спиной к зрителю и не рисуются.
- Не видно ни на одном кадре: внутренние дворовые фасады на уровне двора, точная высота фасадов (оценка по пропорциям).
