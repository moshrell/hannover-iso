HCC / Stadthalle: отчёт после доработки (p_hcc)

Что сделано
Крыша фойе была поставлена вдоль фасада, теперь коньком поперёк, фронтоном к Theodor-Heuss-Platz, как на кадрах v_09/v_10. На фронтоне медальон, карниз. Главный фасад фойе (34,7 x 12 м): две ряда окон между лизенами, портик с четырьмя колоннами, тёплые двери, балкон с ограждением, в верхнем ряду по центру три окна. Вечером фасад получает лёгкую фиолетовую подсветку (по ночному фото hcc-nacht, это подсветка мероприятия), портик тёплый.
Купол, кольцо, корпуса из 16 частей OSM r17296064 оставлены как были (силуэт и порядок частей совпадают с кадрами).
Размеры: fit x1.0 (len 140, точка по якорю 140 x 140). Точка (pin) над центром купола. Ориентация на карте по OSM, face не нужен: фойе на севере, на карте оно сзади (как и в жизни при взгляде с ЮВ).
card_phi = 180: карточка показывает здание с севера, фойе с портиком спереди, купол за ним. Ошибок порядка рисования нет (проверены 0, 90, 180, 270).

По аналогии
Южные и восточные корпуса только по высотам OSM. Ритм окон и свет приблизительные. Лантерна и купол по OSM (полусфера с рёбрами).

Проверенные факты
Bonatz и Scholer, конкурс 1910, строительство 1912 по 1914, открытие 1914, 3600 мест, реставрация зала 2015/16 (en.wikipedia, visit-hannover.com). Адрес Theodor-Heuss-Platz 1-3, 30175 Hannover (visit-hannover.com). Не сверено: точные размеры купола, в текст не включены.

Нужно от сборщика и core
1. Здание вне зоны детальных плиток (до 9.7618, HCC на 9.7696): нужна зона для render-tiles.
2. Части лежат только как building:part в OSM-API (ref/hcc/gen/stadthalle.osm); osm-extract их не берёт.
3. Отель (Congress Hotel am Stadtpark, w37761420) не рисуется, остаётся обычным домом.
4. Лёгкая подсветка фасада фойе: класс wsl с атрибутом fill (как в Linden).
Нужны от Степана кадры: крупно портик и колонны вблизи под углом, южная и восточная стороны корпусов.
