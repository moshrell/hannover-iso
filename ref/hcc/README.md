# HCC / Stadthalle — отчёт

**Что нарисовано.** Модуль `landmarks/hcc.js` строится из 16 частей OSM-отношения r17296064 (`building:part`): кольцо (0–15 м, пологая крыша-юбка), барабан (15–27 м), зелёный купол (27–39 м) с лантерной, фойе с двускатной медной крышей, красный длинный корпус и серые залы. Перекрывающиеся в плане части обрезаны (выше → побеждает); 55 выпуклых кусков с собственной сортировкой. Крыши (конус, седло, вальма, купол с рёбрами) считаются из контура. Окна — один `<path>` на класс×этаж. SVG ≈ 49 КБ.

**Сравнения.** `vergleich-1.png` (v_01, силуэт и порядок частей совпадают), `vergleich-2.png` (v_06), `vergleich-3.png` (v_10, ракурс подбирался на глаз).

**По аналогии / не сделано.** Портик и колонны фойе (в ISO-ракурсе фойе стоит на северной, дальней от камеры стороне, вход не виден); восточные и южные корпуса — только по OSM-высотам; ритм окон и свет приблизительные. Лантерна и кольцо — по OSM, форма купола — полусфера.

**Непроверенные факты.** Архитекторы Paul Bonatz и F. E. Scholer, 1911/12–1914, ~3 600 мест (en.wikipedia, visit-hannover.com — совпадают); дата открытия и размеры купола — без второго источника, в текст не включены.

**Нужно от сборщика/core.**
1. Здание вне зоны детальных плиток (core bbox до 9.7618, HCC на 9.7696): нужна зона для `render-tiles`.
2. Данные части лежат только как `building:part` в OSM-API (`ref/hcc/gen/stadthalle.osm`, генератор `gen-hcc.py`, `embed.py`); osm-extract их не берёт.
3. Якорь `point` [52.37555, 9.76955, 140 м] без `osm` (прямоугольник по умолчанию); дома в квадрате prep убирает.
4. Отель (Congress Hotel am Stadtpark, w37761420) не рисуется, остаётся обычным домом.
5. Лицевая сторона (фойе) смотрит на север — на карте «спиной» к камере; `face` не ставил, чтобы не разворачивать здание против реальности.
