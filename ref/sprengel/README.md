# Sprengel Museum Hannover — отчёт (ветка lm/sprengel)

OSM way 560955703. Файлы: `landmarks/sprengel.js`, `landmarks/meta/sprengel.json`, `ref/sprengel/`.

## Что сделано
- Три объёма рисуются отдельными модулями в повёрнутой (−4,08°) системе здания:
  - **Пристройка 2015** (Meili Peter): тёмный бетон, выступающий верхний этаж над стеклянным цоколем, рельеф панелей, окна, ~10 световых фонарей на крыше.
  - **Здание 1979 (+1992)**: светлые алюминиевые панели, ступенчатая крыша, ряды световых полос.
  - Тёмное стеклянное крыло у площади, козырёк на 4 опорах, бетонная башня, мощёная площадка.
- Окна — `wn` (#FFE7A3), логотипов нет. `face` = ["street",[1,0],"Kurt-Schwitters-Platz"]. Проверки: setup-cloud, studio-shot 390×760 и 1000×700, preview.sh — без ошибок.

## Не получилось / не проверено
- **Высоты нет ни в одном источнике**: 14 м (пристройка 12,4 + фонари) и 9–12 м (старое здание) оценены по пропорциям фото. Не подтверждено двумя источниками.
- Размеры и положение козырька, башни, опор, ширина крыла — оценка по фото.
- Старое здание: S/E/тыльные стороны и внутренний план — по аналогии. Фонари старого здания упрощены до 18 стеклянных полос, трибуна/пандус и скамьи не нарисованы.
- Угловое окно пристройки упрощено (без обхода на S-стену). Баннерная башня и лестница мощёной площадки не детализированы.
- Часть фото из `quellen.txt` могла не скачаться из-за лимитов Wikimedia (429).
- Факты в meta (годы, архитекторы) из общеизвестных данных; независимую сверку по 2 источникам не завершил.
