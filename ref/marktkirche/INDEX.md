## Стороны башни (чеклист)
- Запад: 3 жалюзи (верх), узкое окно по оси, ниже высокое окно в стрельчатой нише, внизу ступенчатый стрельчатый портал (работа Gerhard Marcks по двум источникам; материал створок и рельеф на кадрах не читаются). Перед ним низкие ступени.
- Юг: 3 жалюзи, два узких окна по оси, 2 контрфорса по OSM с медными колпаками. Фронтон: на кадрах не виден (нарисован по аналогии с N/E).
- Север: 3 жалюзи, одно окно, фронтон с пентаграммой и крестом (v_06, v_08).
- Восток: 3 жалюзи, окно; фронтон с пентаграммой и 2 щелями (v_04).
- Крыши башни и шпиль: медь с патиной (зелёные), на теневых кадрах выглядят серо-синими.
- Часовых циферблатов на кадрах нет (в прошлой версии они были нарисованы «по аналогии» — убраны).
