# Marktkirche — отчёт
Новый модуль `landmarks/marktkirche.js` (старый вырезан: `landmarks/altstadt.js` удалён, в нём был только он). План по OSM w5121355: башня 13,9×15,4 м (x 1,8…15,7), трёхнефный зал 42,5×26,7 м с 7 контрфорсами на южной стороне, хор — 5-гранный, крутая крыша с вальмом, башня: щелевые проёмы с жалюзи, 4 фронтона с часами/звездой, крестовая кровля, тонкий шпиль (≈ 98 м).
| сторона | кадры |
|---|---|
| юг, восток | v_04, v_05, v_06 |
| север | v_06, v_08 |
| запад | v_05, v_08 (портал не нарисован) |
## По аналогии / не проверено
- Какие фронтоны башни несут часы (нарисованы на S/E/W, звезда на N) — по кадрам проверено только N; остальные по аналогии.
- Высоты (карниз 18, конёк 44, шпиль ≈ 97 м) оценены по кадрам; источники фактов: Википедия, OSM.
- Крыша западной части за башней и точная геометрия хора приближены.
- Окна на видимых сторонах — ритм по кадрам, без пересчёта.
## Для сборщика / core
- Размещение: `osm` w5121355 проверить на карте (`face` compass [0,1]). Карта-превью `tools/preview.sh` без `SCENE.region` даёт пустой кадр.
- Сверка: `vergleich-1.png` (один круг: силуэт и пропорции совпадают; башня на кадре чуть шире).
