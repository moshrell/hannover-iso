Отчёт: Heizkraftwerk Linden (доработка p_heizkraftwerklinden)

Что сделано
Здание перерисовано по реальным размерам (камера подогнана по кадрам Google Earth, опорные точки OSM). fit x1.0, длина 149,8 м, ориентация по OSM-контуру w45336252 проверена на карте (preview.sh).
Три башни 14,6 x 29 x 65,5 м (стекло, кирпичные панели на широких торцах), трубы A (r 2,75, 124 м), B (тонкая мачта 122 м и барабан), C (серебристая, 125 м), машзал 130 x 22,7 x 22 м, NW-пристройка (кирпич, 11 м) с цилиндром на крыше, SE-пристройка (белый блок 17 м и кирпичный 13 м). Точка pin по центру над зданием. card_phi = 90 (видны панели всех трёх башен).

Сторона -> кадры
SE торцы, машзал: v_03. SW широкие грани и трубы: v_01, v_02, v_05. NW-пристройка: v_04.

По аналогии (кадров мало)
NE (задняя) сторона машзала и крыша машзала у NW-конца, детали SE-пристройки.
Цвета подсветки: по тексту источников (красный, фиолетовый), ночных кадров нет.

Непроверенные факты
Высота башен 65,5 м измерена по кадрам, источники дают 60 м и более.
Архитектор неизвестен, поле arch пропущено.

Сравнения
vergleich-1..3.png старые, vergleich-4.png (v_01) и vergleich-5.png (v_03) после переделки. Расхождения: у башен кирпичные панели выглядят темнее из-за вечерней подсветки.

От core и сборщика: ничего не нужно.
Нужны от Степана: ночные кадры (цвета LED), вид на NE-сторону, крупно SE-пристройка.
