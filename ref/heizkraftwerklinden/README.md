# Heizkraftwerk Linden (ТЭЦ Линден, «Drei warme Brüder» — «три тёплых брата»)

## Что нарисовано
- Три башни котельной 29×22 м, крыши ≈64,5 м: сине-серое остекление с сеткой, кирпично-оранжевые панели на торцах, крышные надстройки.
- Трубы: 125 / 125 / 120 м с кольцами, у башен 1 и 3 короткие патрубки, у башни 2 барабан-шумоглушитель.
- Машинный зал вдоль Ihme (Име), плоская крыша; NW-пристройка (кирпич); SE-пристройка (кирпич + белое).
- Вечер: класс `wsl` с красной/фиолетовой/малиновой заливкой башен (подсветка с 2013 г.).
