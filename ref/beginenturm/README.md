# Beginenturm (Бегинентурм, башня городской стены, ≈1357)

## Что нарисовано
- Круглая башня из светлого бутового камня: основание чуть расширено, два пояса-уступа (≈8 и ≈15 м), слабые линии кладки, две бойницы и герб (щит) на верхней трети, консольный венец.
- 12-гранная черепичная пирамидальная кровля, красная, с кольцом рядов черепицы; почти без свеса.
- Размеры: радиус стены 4,9 м (контур OSM w31290856 ≈ 9×10 м), стена ≈21 м, кровля ≈6 м, всего 27 м.
- Пристроенная стена музея (Historisches Museum) не рисуется — это отдельное здание.

## Непроверенные факты
- Высота 27 м взята из старой меты, по двум источникам не перепроверена.
- Центр ширины: OSM-контур 8,7×10,4 м, возможно включает пристройку.
- Кадр v_05 показывает квадратную башню с открытой звонницей — в OSM/на карте не идентифицирована, не нарисована.
