# Aegidienkirche (руина-мемориал): отчёт агента здания

Ветка `lm/aegidienkirche`. Файлы: `landmarks/aegidienkirche.js`, `landmarks/meta/aegidienkirche.json`, `ref/aegidienkirche/` (INDEX.md, vergleich-1/2.png, foto/). Модуль вырезан из `landmarks/mitte.js` (старый v1 удалён там) и нарисован заново.

## Что нарисовано
- План по контуру OSM (r7359339): башня 8,8 × 10,3 м на западе, трёхнефная зальная церковь (Hallenkirche) 36 × 21 м без крыши и сводов, пять пролётов (контрфорсы по OSM через 6–7,5 м), многоугольный хор (3/8) на востоке, ниже нава.
- Южная стена снаружи: пять стрельчатых проёмов без заполнения, фронтон над каждым пролётом, контрфорсы с пирамидками. Северная стена изнутри: та же сетка, внутренняя тень. Восточные торцы боковых нефов с фронтоном и проёмом. Хор: пять видимых стен с узкими окнами и малым фронтоном над восточной.
- Башня: нижний ярус с кирпичной арковой гранью к нефу, цокольный карниз, башенный ярус с узким окном, карниз, ярус часов, венчающий карниз; медная часть 1958 г.: восьмигранный объём, открытый фонарь «песочные часы», плоский колпак с загнутым краем, шпиль. Общая высота ≈ 57 м.
- Руина: пустые проёмы рисованы тёмными дырами (`wn off`), не светятся. Светятся только часы и слабое ядро колокольного яруса в фонаре.
- Ориентация: башня на западе (то же, что в `data/prep.py`: «Turm nach Westen»); `face` в meta добавлен для порядка, prep его для этого здания не читает.

## Что не видно на кадрах / нарисовано по аналогии
- Нижний ярус башни (0–16 м) закрыт стеной нефа и деревьями: рисунок упрощён (кирпичная заплата с аркой и малым окном по v_01, камень с одним окном по v_06).
- Высота стен нефа (10 м + фронтон 5,4 м) и хора (8,4 м) оценена по v_01 и v_06 с точностью около ±2 м; рваные верхние кромки стен (в жизни неровные, особенно северная) не рисовались, стены и фронтоны ровные.
- Форма хора: контур OSM грубый, грани подобраны (3 видимых + 2 боковые), число и ширина окон хора по v_01–v_03 примерно.
- Ночных кадров нет: освещённость фонаря (слабое свечение колокольного яруса) взята по принципу проекта, не по факту. Если на фото ночью фонарь тёмный, нужно убрать класс `lant` в строке с `'lant', 0` и оставить только `brz`.
- Внутри нефа: колонн и обломков нет (на кадрах пол пустой).

## Факты, не сверенные по двум источникам
- Высота башни ≈ 57 м: ни в одном проверенном источнике не названа; оценка по пропорциям кадров (OSM даёт 13 м с пометкой «just estimated for 3D»). Если нужен точный размер, нужен документ с замером.
- «Um 1347» (Wikipedia: Bau 1347) — второй источник не проверялся; год барочного фасада башни в источниках расходится (Wikipedia 1703–1711, visit-hannover 1703–1717), в тексте стоит «Anfang des 18. Jahrhunderts» («начало XVIII века»).
- Колокол из Хиросимы: подарок 1985 г., висит у входа в башню, звонит 6 августа (Wikipedia). Год превращения руины в мемориал в тексте не указан (в старом тексте стояло 1952, по двум источникам не подтверждено).

## Что нужно от `core/` и сборщика
- Новых материалов в `core/` не нужно. Использованы `rs`, `bk`, `cu`, `brz`, `lant`, `pave`, `ishade`, `wn off`.
- Здание внутри зоны детальных плиток (`core` в `data/bbox.json`), расширять зону не нужно.
- Сборщику: `python3 tools/build-landmarks.py`, затем точечные плитки вокруг 52.3694, 9.7393 (радиус ≈ 80 м).
- Инструменты (не мои файлы, не правил): `tools/map-crop.mjs` (и `preview.sh`) выдаёт пустую картинку, потому что не вызывает `SCENE.region([...])` перед `SCENE.view`; для проверки я использовал временный скрипт (не закоммичен). `tools/studio-shot.mjs`, `map-crop.mjs` по умолчанию ищут Chromium `chromium-1194`, в облаке стоит `chromium-1243`: запускать с `CHROME=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`.
