# Aegidienkirche (руина-мемориал): отчёт после доработки

Ветка `lm/p_aegidienkirche`. Мои файлы: `landmarks/aegidienkirche.js`, `landmarks/meta/aegidienkirche.json`, `ref/aegidienkirche/`.

## Итог по пунктам задания
- **Размеры.** `len` = 50,3 м = наибольшая сторона OSM-контура (r7359339: 50,3 × 21,3 м), итоговый `fit` на карте = **1,00** (было 0,986). Рисунок в метрах по контуру OSM: башня 8,8 × 10,3, зальная церковь 36 × 21, хор до x = 58,4.
- **Карта.** Башня на западе, камера карты (ЮВ) видит южную стену снаружи, восточные торцы и хор, как на v_06 (камера ВЮВ). Ориентация и `face` не менялись: здание стоит на своём месте, остатков старых OSM-домов нет (`tools/preview.sh aegidienkirche 1.5`).
- **Карточка.** `card_phi` = **0**. Проверил 0 / 90 / 180 / 270: только при 0 видны восточная грань башни с кирпичной аркой, внутренность нефа и южная стена с фронтонами (то есть тот же вид, что на кадрах v_01 и v_06); остальные углы прячут нав или показывают глухие тыльные стены. Ошибок порядка рисования нет.
- **Точка.** `pin: [33.2, 11.1, 21]` в модуле: над серединой плана (центр контура), чуть выше фронтонов (верх стен ≈ 16,4 м). Раньше точка стояла над шпилем башни, то есть на краю здания. Если Степан хочет точку над башней (верх 57 м), это одна строка: убрать `pin`.
- **Плавность.** В карточке 516 SVG-узлов, ошибок консоли нет, облегчать не нужно.
- **Метаданные.** Заполнены `title`, `fact`, `studio`, `seo` (116 слов), `addr`, `year`, `arch`; `minor` = false (здание заметное).

## Что нарисовано нового в этом проходе
- Фронтоны над пролётами теперь разной сохранности, как у настоящей руины: на южной стене четвёртый фронтон обломан (рваная кромка), на северной (внутренней) третий; остальные ниже или выше на 4–20 %. Раньше все пять были одинаковыми.
- Текст `studio` исправлен (год барочной фасады 1703–1711 вместо «Anfang des 18. Jahrhunderts», год 1943 оставлен общим «Oktober 1943», сказано, что уцелели «Teile der Seitenwände»).

## Что остаётся (честно)
- Верхние кромки стен нефа в жизни рваные по всей длине, у меня ровные, рваные только отдельные фронтоны. Точный рельеф кромок по кадрам v_01–v_06 не снять, надёжнее доснять крупный кадр (см. ниже).
- Хор в жизни шире и богаче (большие стрельчатые проёмы восточной стены, остатки сводов); у меня упрощённый 3/8-многоугольник по OSM с узкими окнами. Хор нарисован по аналогии, число окон приблизительно.
- Нижний ярус башни (0–16 м) закрыт стеной нефа и деревьями: кирпичная заплата с аркой и малым окном по v_01, камень с одним окном по v_06. Реальный цвет там темнее и закопчённее, чем в палитре проекта.
- Ночных кадров нет: освещённость фонаря (слабое свечение колокольного яруса) выбрана по принципу проекта. Если на фото ночью фонарь тёмный, нужно убрать класс `lant` в строке с `'lant', 0` и оставить `brz`.
- Внутри нефа колонн и обломков нет (на кадрах пол пустой). Скульптуру «Demut» (Kurt Lehmann, 1959) не рисовал: на кадрах её не видно.

### Какие кадры нужны Степану (по желанию)
1. Крупно с востока, с высоты ≈ 25 м: хор и восточные торцы нефов (форма проёмов и число окон хора).
2. Крупно с юга по оси южной стены: рваные верхние кромки и сохранность каждого фронтона.
3. Ночной облёт башни: что светится на самом деле (часы, фонарь, подсветка фасада).

## Факты и источники
- Сверено по двум источникам: Baubeginn 1347 (Wikipedia en, stadthistorie.info); барочная фасада башни 1703–1711, автор Sudfeld Vick (Wikipedia en, structurae.net; visit-hannover называет 1703–1717, в тексте стоят 1703–1711); Zerstörung 1943 (все); Glockenspiel/Turmaufsatz 1958 (hannover-entdecken.de, dta-uni-hannover.de; stadthistorie.info показывает уже достроенную вершину на снимке 1961 г.); Friedensglocke из Hiroshima 1985, звонит 6 августа (Wikipedia en, hannover-entdecken.de, dta-uni-hannover.de).
- **Не сверено по двум источникам:** адрес «Aegidienkirchhof 1, 30159 Hannover» (один источник, dta-uni-hannover.de; остальные называют только угол Breite Straße / Osterstraße); «медная» часть башни (медь ни одна страница не упоминает прямо, зелёный цвет виден на кадрах).
- **Высота башни ≈ 57 м не подтверждена:** ни в одном проверенном источнике нет числа (OSM даёт 13 м с пометкой «just estimated»). Оценка по пропорциям кадров, точность ±3 м. Нужен документ с замером.
- Год превращения руины в мемориал: Wikipedia en называет 1952, второго источника нет, поэтому в тексте не указан.
