# Задание: свет и плавность анимации в карточках (ветка `lm/p_licht`)

Ты — агент общей части карточек проекта hannover-iso (репозиторий `moshrell/hannover-iso`, ветка `main`). Общайся со Степаном по-русски, кратко, немецкие слова сразу переводи в скобках. Порядок: `prompts/START.md`, `ARBEIT.md`, `CLAUDE.md`. Здания не перерисовывай (это отдельные задачи `p_<id>`): твои файлы — `studio.js`, `studio.css` и (только если без этого никак) `core/iso.css`; в `core/iso-core.js` ничего не меняй без необходимости, опиши в отчёте.

## Что не так (замечания Степана)
1. После включения света окна в карточке «живут» только у горстки (в `studio.js` мерцают 14 окон, остальное неподвижно). На больших зданиях это не видно, получается, что окна больше не гаснут сами. Нужно живое здание: небольшая доля окон (порядка нескольких процентов, число зависит от размера здания) изредка гаснет и снова зажигается мягко, а не рывком; общий вид должен оставаться спокойным. Учти, что окна в части зданий сгруппированы в один `<path>` на класс (например Ihme-Zentrum): там мерцание по окнам невозможно, придумай способ, который работает для всех (например, через слои групп или маску), без роста числа узлов.
2. Выключение света: окна должны гаснуть **вместе** с уходом света фасада (одновременно, волной в ту же сторону), а не «сначала ушёл свет, потом начали гаснуть окна». Сейчас `OFF` в `studio.js` задаёт для окон `win0: 2.4`, а для фасада `flood0: .3`.
3. Во многих карточках анимации идут рывками. Найди причину (число анимируемых элементов, `transition` на тысячах узлов, фильтры `wglow`/`bloom`, пересчёт стилей) и сделай плавно на среднем телефоне; измерь до/после (число кадров в секунду при включении света на самых тяжёлых зданиях: Ihme-Zentrum, Neues Rathaus, Welfenschloss, NORD/LB, HCC; можно искусственно замедлить процессор в Playwright через CDP `Emulation.setCPUThrottlingRate`).
4. Никаких `style="…"` в разметке (CSP сайта): стили из JS только через `element.style`.
