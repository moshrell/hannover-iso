# Старт для агента здания (единая точка входа)

Тебя запустили короткой фразой: «Зайди в репозиторий moshrell/hannover-iso (ветка main), прочитай prompts/START.md и выполни». Дальше всё здесь.

1. Клонируй репозиторий (`git clone https://github.com/moshrell/hannover-iso.git`) или обнови (`git checkout main && git pull origin main`): очередь и инструменты меняются, нужна свежая версия.
2. Прочитай `CLAUDE.md`, `ARBEIT.md`, `prompts/VIDEO-ARBEIT.md`.
3. Посмотри очередь: `python3 tools/queue.py` (занято = на сервере уже есть ветка `lm/<id>`; такое здание НЕ трогай, даже если работа выглядит брошенной: решает Степан).
4. Возьми здание: `python3 tools/queue.py claim`. Команда сама берёт первое свободное здание со статусом `ready`, создаёт ветку `lm/<id>` и пушит её (это и есть пометка «взято»). Если пишет «СВОБОДНЫХ ЗДАНИЙ НЕТ» — сообщи Степану и остановись. Если пишет «ОШИБКА при создании ветки» — приведи Степану текст ошибки (скорее всего нет прав на push); ничего не выдумывай. Статус `ready` в `QUEUE.md` у всех свободных зданий проставлен, кадры лежат в `ref/<id>/foto/` (это можно не проверять).
5. Читай `prompts/<id>.md` для своего здания и выполняй `prompts/VIDEO-ARBEIT.md`. Материал — готовые кадры `ref/<id>/foto/v_*.jpg` в репозитории (видео и компьютер Степана не нужны). Работай только в ветке `lm/<id>`, правила файлов — `ARBEIT.md`.
6. Один чат = одно здание. Закончил — сдай отчёт (`ref/<id>/README.md`) и скажи Степану. Второе здание не бери без его слова.

Если Степан назвал конкретное здание («возьми marktkirche»), пропусти п. 4 и вместо `claim` создай ветку сам только если `lm/<id>` ещё нет на сервере.
