# Задание: Christuskirche Hannover (ветка `lm/christuskirche`)

Ты работаешь над проектом hannover-iso (изометрическая ночная карта Ганновера, репозиторий moshrell/hannover-iso). Общайся со Степаном по-русски, кратко, немецкие слова сразу переводи в скобках. Всё нужное лежит в GitHub, доступ к компьютеру Степана тебе не нужен.

## Здание
Christuskirche Hannover, Nordstadt (Hannover-Nordstadt), неоготическая кирпичная церковь с высокой башней и шпилем (архитектор Conrad Wilhelm Hase).
OSM-контур: way 7655778 (в `data/osm.json.gz`). Имя в проекте: `christuskirche`.

## Шаг 1. Код
```
git clone https://github.com/moshrell/hannover-iso.git   # или в готовой папке: git fetch origin
cd hannover-iso && git checkout -b lm/christuskirche origin/main
```
Прочитай `README.md`, `CLAUDE.md`, `ARBEIT.md` и строго следуй им (правила файлов, координаты внутри стены, проверки, отчёт). Правь ТОЛЬКО `landmarks/christuskirche.js`, `landmarks/meta/christuskirche.json`, `ref/christuskirche/`. В `main` не пушить.

## Шаг 2. Заготовка
`python3 tools/new-landmark.py christuskirche "Christuskirche Hannover" 7655778 <высота в м>` (высоту найди в источниках, проверь по двум).

## Шаг 3. Фото со ВСЕХ сторон (обязательно до рисования)
Скачай не меньше 12 фото разными запросами, чтобы закрыть каждую сторону здания, и ОТКРОЙ их (Read), а не просто скачай:
`python3 tools/ref-dl.py "<запрос>" ref/christuskirche/<префикс> 6`
Запросы: "Christuskirche Hannover", "Christuskirche Hannover Turm", "Christuskirche Hannover Portal", "Christuskirche Hannover Seitenansicht", "Christuskirche Hannover Chor", "Christuskirche Hannover Luftbild", "Christuskirche Hannover Rückseite". Добавь поиск по Wikimedia Commons-категории здания, виды сверху (Luftbild), детали (портал, окна, карниз, кровля, цоколь). Составь в `ref/christuskirche/README.md` таблицу «сторона здания → какие фото её показывают». Если на какую-то сторону фото нет, найди ещё; если всё равно нет, ЧЕСТНО отметь в отчёте, что сторона рисуется по аналогии, и не выдумывай деталей.

## Шаг 4. Рисование: максимально реалистично
Качество: никакой «смазанности» и упрощения. Каждая видимая сторона и каждая деталь рисуются по своим фото: пропорции этажей и окон, ритм окон, карнизы и пояса, цоколь, порталы и входы, крыши с их реальным уклоном, трубы, мелкие надстройки, материалы и цвет облицовки, элементы декора. Не обобщай («типовые окна во всех рядах»), если на фото ряды разные. Сначала правда (как в жизни), потом красота. Не рисуй того, чего нет на фото (фонтаны, пристройки, скульптуры без фото). Стиль проекта: тёмный фон, тёплый свет окон `#FFE7A3`, один ракурс (вид с юго-востока), без вращения. Свои рисунки по фото, фото не копировать, логотипов нет.
Здесь важно: кирпичная кладка с поясами и рельефными деталями, высокая башня (этажи колокольни, часы, ярусы окон, шпиль с пинаклями), абсида и хор, стрельчатые окна с реальным делением, контрфорсы, крыши нефа и приделов. Убедись, что высокая башня целиком помещается в кадр на телефоне 390 px.
Лицевая сторона на карте: подбери поле `face` в `landmarks/meta/christuskirche.json` по правде (куда смотрит главный фасад по OSM и фото). Если нужна функция или материал, которых нет в `core/`, не правь `core/`, а напиши в отчёте.

## Шаг 5. Проверки (по ARBEIT.md, по порядку)
1. `sh tools/setup-cloud.sh` (один раз за сессию).
2. `node tools/studio-shot.mjs christuskirche 390 760` и `node tools/studio-shot.mjs christuskirche 1000 700`: открой картинки `/tmp/studio_christuskirche.png`, сравни с фото сторона за стороной. Здание целиком в кадре на телефоне, нет проколов геометрии и сортировки.
3. `sh tools/preview.sh christuskirche 1.5` → `/tmp/map_christuskirche.png`: фасад обращён как в жизни, здание на своём месте, нет приросших кусков старых OSM-домов.
4. Заполни meta: `title`, `fact` (одна строка под картой), `studio` (текст в окне; факты проверяй минимум по двум источникам), `minor`, `rank`.
Повторяй рисование и проверки, пока не станет похоже на фото в каждой видимой детали.
