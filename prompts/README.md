# Задания для чатов-зданий

**Запуск агента — одна фраза** (чат должен быть открыт в приложении на компьютере Степана, чтобы видеть `D:\Webdesign\hannover-iso\_fotos\`):

```
Зайди в репозиторий moshrell/hannover-iso (ветка main), прочитай prompts/START.md и выполни.
```

Что происходит дальше:
- `START.md` — единая точка входа: что прочитать, как взять здание.
- `QUEUE.md` — очередь зданий (порядок = приоритет, статусы `ready` / `wartet` / `fertig`; статусы ставит сборщик).
- `python3 tools/queue.py` — показывает свободные и занятые; `python3 tools/queue.py claim` — берёт первое свободное: создаёт и пушит ветку `lm/<id>` (ветка на сервере = «занято», создание атомарно).
- `<id>.md` — задание по конкретному зданию (данные: OSM, состояние в коде, материал, особенности).
- `VIDEO-ARBEIT.md` — общий порядок работы по видео Google Earth (кадры → разбор → рисунок → сверка → сдача).
- Освободить здание (агент умер, задание передумали): сборщик удаляет ветку `git push origin --delete lm/<id>`.

Старые задания `clemens.md`, `christuskirche.md` — сделаны по Wikimedia-фото, в очереди не участвуют.

## Материал
Степан кладёт видео/фото в `D:\Webdesign\hannover-iso\_fotos\<id>\` (имя папки = id, `<id>.mp4`, фото `<id>-tag.png`, `<id>-nacht.png`). Агент сам режет видео (`tools/frames.sh`) и кладёт отобранные кадры в `ref/<id>/foto/`.
