# Задание: Basilika St. Clemens (ветка `lm/clemens`)

Ты работаешь над проектом hannover-iso (изометрическая ночная карта Ганновера, репозиторий moshrell/hannover-iso). Общайся со Степаном по-русски, кратко, немецкие слова сразу переводи в скобках. Всё нужное лежит в GitHub, доступ к компьютеру Степана тебе не нужен.

## Здание
Basilika St. Clemens, католическая церковь с куполом, Platz an der Basilika / Leibnizufer. Барочно-ориентированная архитектура с главным куполом.
OSM-контур: way 357786647 (в `data/osm.json.gz`). Имя в проекте: `clemens`.

## Шаг 1. Код
```
git clone https://github.com/moshrell/hannover-iso.git   # или в готовой папке: git fetch origin
cd hannover-iso && git checkout -b lm/clemens origin/main
```
Прочитай `README.md`, `CLAUDE.md`, `ARBEIT.md` и строго следуй им (правила файлов, координаты внутри стены, проверки, отчёт). Правь ТОЛЬКО `landmarks/clemens.js`, `landmarks/meta/clemens.json`, `ref/clemens/`. В `main` не пушить.

## Шаг 2. Заготовка
`python3 tools/new-landmark.py clemens "Basilika St. Clemens" 357786647 <высота в м>` (высоту найди в источниках, проверь по двум).

## Шаг 3. Фото со ВСЕХ сторон (обязательно до рисования)
Скачай не меньше 12 фото разными запросами, чтобы закрыть каждую сторону здания, и ОТКРОЙ их (Read), а не просто скачай:
`python3 tools/ref-dl.py "<запрос>" ref/clemens/<префикс> 6`
Запросы: "St. Clemens Hannover", "Basilika St. Clemens Hannover Kuppel", "Clemenskirche Hannover Fassade", "St. Clemens Hannover Seitenansicht", "St. Clemens Hannover Rückseite", "St. Clemens Hannover Luftbild", "St. Clemens Hannover Portal". Добавь поиск по Wikimedia Commons-категории здания, виды сверху (Luftbild), детали (портал, окна, карниз, кровля, цоколь). Составь в `ref/clemens/README.md` таблицу «сторона здания → какие фото её показывают». Если на какую-то сторону фото нет, найди ещё; если всё равно нет, ЧЕСТНО отметь в отчёте, что сторона рисуется по аналогии, и не выдумывай деталей.

## Шаг 4. Рисование: максимально реалистично
Качество: никакой «смазанности» и упрощения. Каждая видимая сторона и каждая деталь рисуются по своим фото: пропорции этажей и окон, ритм окон, карнизы и пояса, цоколь, порталы и входы, крыши с их реальным уклоном, трубы, мелкие надстройки, материалы и цвет облицовки, элементы декора. Не обобщай («типовые окна во всех рядах»), если на фото ряды разные. Сначала правда (как в жизни), потом красота. Не рисуй того, чего нет на фото (фонтаны, пристройки, скульптуры без фото). Стиль проекта: тёмный фон, тёплый свет окон `#FFE7A3`, один ракурс (вид с юго-востока), без вращения. Свои рисунки по фото, фото не копировать, логотипов нет.
Здесь важно: купол с барабаном и фонарём (форма, окна барабана, рёбра, цвет кровли), башни и фронтон главного фасада, портал, колонны и пилястры, окна нефа, боковые фасады и пристройки. Кровля купола по фото, а не «полусфера».
Лицевая сторона на карте: подбери поле `face` в `landmarks/meta/clemens.json` по правде (куда смотрит главный фасад по OSM и фото). Если нужна функция или материал, которых нет в `core/`, не правь `core/`, а напиши в отчёте.

## Шаг 5. Проверки (по ARBEIT.md, по порядку)
1. `sh tools/setup-cloud.sh` (один раз за сессию).
2. `node tools/studio-shot.mjs clemens 390 760` и `node tools/studio-shot.mjs clemens 1000 700`: открой картинки `/tmp/studio_clemens.png`, сравни с фото сторона за стороной. Здание целиком в кадре на телефоне, нет проколов геометрии и сортировки.
3. `sh tools/preview.sh clemens 1.5` → `/tmp/map_clemens.png`: фасад обращён как в жизни, здание на своём месте, нет приросших кусков старых OSM-домов.
4. Заполни meta: `title`, `fact` (одна строка под картой), `studio` (текст в окне; факты проверяй минимум по двум источникам), `minor`, `rank`.
Повторяй рисование и проверки, пока не станет похоже на фото в каждой видимой детали.

Коммиты по-русски, только свои файлы: `git add landmarks/clemens.js landmarks/meta/clemens.json ref/clemens` (НЕ `git add -A`), `git push origin lm/clemens`.
ОТЧЁТ обязательно ФАЙЛОМ `ref/clemens/README.md`: что сделано, таблица сторон и фото, что не удалось и почему, какие факты не сверены, что нужно от `core/` или сборщика. Закоммить и запуши. Коротко повтори в чате.
