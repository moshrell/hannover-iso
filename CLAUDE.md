# hannover-iso — правила для Claude

- Общение со Степаном по-русски, кратко; немецкие термины сразу переводить в скобках.
- Стиль: тёмный фон #0A0E0C, тёплый свет #FFE7A3, свои рисунки по фото-референсам (Wikimedia), без палитр скилла ISO-glow (от него только формула проекции, MIT — копирайт не удалять).
- Один ракурс (вид с юго-востока, как в `rathaus.html`); вращения нет.
- Мобильная версия в первую очередь; без библиотек (всё своим кодом).
- Подпись «© OpenStreetMap-Mitwirkende (ODbL)» на карте обязательна.
- Страницы без встроенных `<script>`/`<style>` и без `style="…"` в разметке (CSP сайта). Стили из JS — только через `element.style`.
- После изменений карты: `tools/sync-vorschau.sh ../kravets-site`, коммит в kravets-site (сообщение по-русски), push в `master` → https://kravets-webdesign.de/vorschau/karte-ksn0/
- README держать актуальным: правки на месте, устаревшее удалять.
- Клиенты на карте — только с письменного согласия.
